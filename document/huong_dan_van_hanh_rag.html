Huong Dan Van Hanh Project RAG

Tai lieu nay mo ta cac buoc chay, muc dich tung lenh CLI, va quy trinh review anh thu cong.

1) Muc tieu he thong

  • Text index: phuc vu tra loi noi dung van ban SGK.
  • Image index: phuc vu tim anh minh hoa lien quan cau hoi.
  • Human review: cho phep sua caption va loai bo anh sai truoc khi retrieval.

2) Chuan bi moi truong

2.1 Cai dependencies

pip install -r requirements.txt

2.1b Neu chay tren Google Colab

Can cai them thu vien he thong cho pdf2image va OCR tieng Viet:

!apt-get update
!apt-get install -y poppler-utils
!apt-get install -y tesseract-ocr tesseract-ocr-vie

2.2 Tao file .env

cp .env.example .env

2.3 Bien quan trong

  • HF_TOKEN: bat buoc de tai model Hugging Face.
  • USE_GPU: bat/tat GPU.
  • IMAGE_CAPTION_ENABLED: bat/tat caption model cho anh.
  • IMAGE_EXTRACTION_VERSION: version thuat toan extract image.
  • IMAGE_REVIEW_MANIFEST_PATH: noi luu manifest review anh.

3) Danh sach lenh va muc dich

Lenh Muc dich
python main.py --text-only ETL chi text (OCR + chunk + index text).
python main.py --image-only ETL chi image (extract + metadata + index image).
python main.py --etl ETL full text + image trong 1 lan chay.
python main.py --export-image-review <output.json> Export danh sach anh de review caption/xoa anh khong lien quan.
python main.py --apply-image-review <review.json> --review-user <name> Apply ket qua review vao vector DB.
python main.py --export-image-review <output.json> --review-pdf "<file.pdf>" Export review theo 1 PDF cu the.
python main.py --export-image-review <output.json> --review-include-completed Export ca item da review (khong chi pending).
python main.py --app Mo giao dien Gradio de hoi dap.

4) Quy trinh khuyen nghi

Kich ban A: Khoi tao moi hoan toan

  1. Xoa DB cu:
Remove-Item -Recurse -Force "D:\personal_repo\project_rag\database"
New-Item -ItemType Directory -Path "D:\personal_repo\project_rag\database" | Out-Null
  1. Chay ETL text:
python main.py --text-only
  1. Chay ETL image:
python main.py --image-only
  1. Export file review:
python main.py --export-image-review database/review_images.json
  1. Sua thu cong cac truong: caption_vi_manual, keywords_vi_manual, review_status, is_active.
  2. Apply review:
python main.py --apply-image-review database/review_images.json --review-user charlie
  1. Mo app:
python main.py --app

Kich ban B: Build nhanh 1 lenh

python main.py --etl

Kich ban C: Chi review 1 tai lieu

python main.py --export-image-review database/review_sgk6.json --review-pdf "SGK KHTN 6 CD.pdf"
python main.py --apply-image-review database/review_sgk6.json --review-user charlie
