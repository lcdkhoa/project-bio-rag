Huong Dan Van Hanh Project RAG

Tai lieu nay mo ta cac buoc chay, cac lenh CLI, va quy trinh review/upsert metadata anh.

1) Muc tieu he thong

  • Text index: phuc vu tra loi noi dung van ban SGK.
  • Image index: phuc vu tim anh minh hoa lien quan cau hoi.
  • Human review + CRUD metadata: sua caption, loai bo anh sai, bo sung item moi.

4) Quy tac review/upsert (quan trong)

  1. --apply-image-review la upsert theo item co trong file JSON, khong phai sync full.
  2. Xoa item khoi JSON array khong dong nghia xoa khoi DB.
  3. Muon loai khoi retrieval: dat review_status=rejected|deleted, hoac is_active=false, hoac delete=true.
  4. --upsert-image-review-item se create neu image_id chua ton tai, update neu da ton tai.
  5. --replace-image-db la sync full theo snapshot: item khong con trong JSON se bi xoa khoi manifest va image index.
