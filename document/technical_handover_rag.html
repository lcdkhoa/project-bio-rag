Technical Handover - Biology RAG

Tài liệu bàn giao kỹ thuật để người mới có thể hiểu kiến trúc, chạy ETL/retrieval và thuyết trình dự án.

1) Kiến trúc tổng thể

Hệ thống gồm 4 lớp: ETL text, ETL image + human review, retrieval hybrid, và Gradio app.

PDF -> OCR text -> chunk -> text vector DB
PDF -> detect/crop image -> metadata -> image vector DB
image manifest -> human review -> apply -> upsert/delete image docs
query -> hybrid retriever -> LLM answer + image gallery

3) Code flow ETL image (block-by-block)

  1. Render page: _extract_page_image().
  2. Region proposal: _detect_contour_regions() (4 chiến lược detector).
  3. Refine & dedupe: _refine_regions(), _deduplicate_regions(), _suppress_container_regions().
  4. Giới hạn số crop/page: _limit_regions_for_extraction(max_regions=24).
  5. CLIP filter: _clip_filter().
  6. Loại crop thiên về text: _ocr_crop_text() + _is_text_dominant_crop().
  7. Enrich metadata: figure label/caption, context OCR, keywords, optional visual caption.
  8. Build search_text, save ảnh, ghi manifest, và mark status theo version.
