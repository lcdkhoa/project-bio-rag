Technical Handover - Biology RAG

Tài liệu bàn giao kỹ thuật: kiến trúc ETL/retrieval và quy trình CRUD metadata ảnh.

1) Kiến trúc tổng thể

PDF -> OCR text -> chunk -> text vector DB
PDF -> detect/crop image -> metadata -> image vector DB
manifest -> export review/db snapshot -> human edit -> apply/upsert -> sync vector DB
query -> hybrid retriever -> LLM answer + image gallery

4) Quy tắc apply/upsert

  1. --apply-image-review là upsert theo item trong JSON, không phải sync full.
  2. Xóa item khỏi JSON array không làm item tự biến mất khỏi DB.
  3. Muốn loại ảnh khỏi retrieval: review_status=rejected|deleted hoặc is_active=false hoặc delete=true.
  4. --upsert-image-review-item: update nếu đã có image_id, create mới nếu chưa có.
  5. --replace-image-db: replace toàn bộ manifest và rebuild image index theo snapshot JSON.
  6. --review-pdf cho phép apply/export theo đúng 1 tài liệu.
Lưu ý: tránh sửa trực tiếp chroma.sqlite3; nên đi qua CLI review/upsert để sync index an toàn.

6) Quick onboarding

  1. Chạy python main.py --help.
  2. Chạy ETL mẫu --text-only + --image-only.
  3. Export review, chỉnh thử 1 item, apply lại.
  4. Test --upsert-image-review-item cho 1 item mới.
  5. Mở Flask API hoặc frontend và kiểm tra gallery retrieve.
